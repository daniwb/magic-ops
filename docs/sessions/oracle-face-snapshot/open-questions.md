# Open architecture questions

1. Should the six semantic-conflict groups remain in universal projections with
   `quarantined` status (the prototype's recommendation), or should publication
   expose a separate admitted-canonical projection?
2. Are the 142 per-printing other-face target-set differences expected partial
   printing evidence, or must they also quarantine canonical semantic groups?
   The union is deterministic, but the prototype does not call it agreement.
3. Should the normal-game candidate exclude every currently proposed
   non-ordinary layout, or should Plane/Scheme/Vanguard and art-series objects
   become separate named projections instead? No choice here is authoritative.
4. A token-template face can share an Oracle identity with cards-collection
   evidence. Is union membership correct, or should template identity include a
   provenance class? The accepted identity currently forbids that extension.
5. Select the durable compressed content-addressed store and retention policy.
   This session uses `/opt/development/magic-ops-artifacts/` only as a local
   prototype store.
6. Cross-release UUID/content continuity remains unmeasured because no adjacent
   pinned AllPrintings payload was legitimately available. Same-release
   reproduction is not a substitute for longitudinal evidence.
