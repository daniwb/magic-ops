name: implement-engine-capability
description: Implement one bounded Engine capability through the staged Engine workflow.
---

Search existing types, registries, converter paths, and execution tests before
adding anything. Refuse an already-present capability; split a mixed request.
Keep the allowed files narrow. Supply a discriminating runtime test that
exercises the target behavior with valid game setup, then run focused tests,
formatting, diff, and scope gates. A dependent Map ticket must consume the new
representation before this capability is considered confirmed.
