---
name: integrate-change
description: Integrate an explicitly approved, gate-passing Factory proposal.
---

Require an explicit integration decision, an accepted receipt, a clean target
tree, and the final ticket gates. Apply only the receipt's patch, rerun the
declared integration gates, record the result, and update dependent ticket
state. Never auto-integrate a parked, failed, unreviewed, or observation-only
proposal; never deploy merely because a patch compiled.
